[Introducing Claude Sonnet 5.5 - Anthropic](https://www.anthropic.com/claude-sonnet-5-5)

[Google unveils Gemini 4 Argon - VentureBeat](https://venturebeat.com/technology/google-unveils-gemini-4-argon-retaking-benchmark-lead-over-openai-and-anthropic-but-in-limited-release)

[OpenAI DevDay 2026 live updates - CNBC](https://www.cnbc.com/2026/09/29/openai-devday-2026-live-updates.html)

## 2. AI dev tools & methodologies (max 5)

- **Claude Code Mods** - Small TypeScript functions that hook into Claude Code's internals to rewrite prompts, intercept or retry tool calls, redact secrets from output, or replace UI elements (e.g. the built-in `/diff` is now a mod). A developer can write a mod (or ask Claude Code to write one) and install it via the existing plugin system to pare Claude Code down or extend it - note Anthropic says mods are unsandboxed and run with full local access. [Customize Claude Code with mods in TypeScript - Claude](https://claude.com/blog/claude-code-mods)
- **Pi 1.0** - Earendil's first stable release of its open-source (MIT), minimal coding-agent harness that runs in the terminal and works with models from almost every provider; already used by hundreds of thousands of people weekly. Developers can drop it in as a lightweight, provider-agnostic daily-driver agent or build custom agentic workflows on top of its harness. [Pi 1.0 - Earendil](https://earendil.com/posts/pi-1-0/)
- **OpenRig** - An open-source harness that runs Claude Code and Codex together as one coordinated agent team, defined in a single YAML file and booted with one command, giving each agent persistent state and shared context. Useful for developers who want to stop juggling separate terminal windows per coding agent and instead run a defined multi-agent "team" against one codebase. [OpenRig - GitHub](https://github.com/mvschwarz/openrig)
- **Google ax** - Google's open-source agentic orchestration runtime for running autonomous agent workloads on Kubernetes, built around Task/Workspace/Model primitives that handle sandboxing, state and LLM config; gained 1,783 stars this week on GitHub trending. Lets teams running many coding/agent tasks in production add isolation and checkpoint/resume without building that infrastructure themselves. [google/ax - GitHub](https://github.com/google/ax)
