# AI Dev Weekly - Week ending 2026-10-11

## 1. New models, products & tools (max 8)

- **REA** (morluto, open source) - An MCP server that gives coding agents reverse-engineering tools, from native binaries and Electron apps to Android APKs and smart contracts. Launched October 5 and already at 69.2k stars; topped GitHub's daily trending chart with +25,784 stars in a single day. [github.com/morluto/rea](https://github.com/morluto/rea)
- **Mistral Large 4** (Mistral AI) - A roughly 1-trillion-parameter mixture-of-experts flagship model; public API preview opened October 6, with open weights due later in October. Widely covered by European tech press; one Hacker News tracker logged 517 points for the announcement. [t3n.de](https://t3n.de/news/mistral-large-4-ki-spitzenmodell-1766941/)
- **OpenMontage** (calesthio, open source) - Billed as the first open-source "agentic video production system," turning a coding assistant into a full video studio with 12 pipelines and 700+ skill files. +3,479 stars this week on GitHub trending, 66.1k total. [github.com/calesthio/OpenMontage](https://github.com/calesthio/OpenMontage)
- **HyperFrames** (heygen-com, open source) - Turns plain HTML/CSS/JS animations into rendered MP4 video, built so coding agents can generate video output directly rather than through a traditional video editor. +4,003 stars this week on GitHub trending, 60.3k total. [github.com/heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)
- **text-to-cad** (earthtojake, open source) - Gives coding agents CAD superpowers: generating STEP/STL/3MF models, running manufacturability checks, and sending jobs straight to 3D printers or CNC services. +2,125 stars this week on GitHub trending, ~19k total. [github.com/earthtojake/text-to-cad](https://github.com/earthtojake/text-to-cad)

## 2. AI dev tools, software & techniques (max 10)

- **skills** (mattpocock, open source) - A curated library of Claude Code/Codex/Copilot/Gemini CLI skills covering spec-driven planning, TDD, structured debugging, and a shared project glossary. The week's #2 repo on GitHub's overall weekly trending chart: +8,156 stars this week, 284k total. [github.com/mattpocock/skills](https://github.com/mattpocock/skills)
- **claude-mem** (thedotmack, open source) - Captures what a coding agent did in a session, compresses it, and re-injects relevant context into future sessions via hybrid semantic+keyword search. +3,850 stars this week, 99.2k total. [github.com/thedotmack/claude-mem](https://github.com/thedotmack/claude-mem)
- **e2e** (tester-army, open source) - An end-to-end testing framework where you describe a goal in plain language; an agent drives the app once, then recorded steps replay deterministically without calling a model again. Nearly all of its 8.7k stars arrived this week (+6,566). [github.com/tester-army/e2e](https://github.com/tester-army/e2e)
- **OpenRig** (mvschwarz, open source) - Runs a persistent, named team of coding agents (Claude Code, Codex, Pi) with defined roles, shared context, and inter-agent messaging over tmux instead of scattered terminal sessions. +2,338 stars this week, 6.7k total. [github.com/mvschwarz/openrig](https://github.com/mvschwarz/openrig)
- **Cursor Plugins** (Cursor) - An official plugin specification and marketplace for packaging skills, rules, and MCP servers for the Cursor editor. +1,125 stars this week, 10.7k total. [github.com/cursor/plugins](https://github.com/cursor/plugins)
- **Diagram Design** (cathrynlavery, open source) - An agent skill that draws 44 types of editorial-style diagrams as self-contained HTML+SVG, matching a site's brand colors and checking text contrast. 48.8k total stars; gained 1,189 in a single day on GitHub's daily trending chart. [github.com/cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)
- **OpenSRE** (Tracer-Cloud, open source) - An open-source toolkit for building AI on-call/SRE agents that gather logs, metrics and traces to diagnose production incidents and post evidence-linked findings to Slack or PagerDuty. 11.7k stars. [github.com/Tracer-Cloud/opensre](https://github.com/Tracer-Cloud/opensre)
- **andrej-karpathy-skills** (multica-ai, open source) - A single CLAUDE.md file distilling Andrej Karpathy's observations on LLM coding pitfalls into four rules: think before coding, simplicity first, surgical changes, goal-driven execution. 218k total stars. [github.com/multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)
