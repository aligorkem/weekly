## 2. AI dev tools, software & techniques (max 10)

- **superpowers** (obra, open source) - An agentic skills framework that encodes a full dev methodology (brainstorming, planning, TDD, systematic debugging, git worktrees) so agents follow a consistent process rather than being called as one-off tools. v7.0.0 shipped October 10, rebuilding the brainstorming skill; 299.8k total stars. [github.com/obra/superpowers](https://github.com/obra/superpowers)
- **ECC (Everything Claude Code)** (affaan-m, open source) - An agent-harness optimization system adding reusable skills, cross-session memory and security tooling on top of Claude Code, Codex, Opencode and Cursor. 280.2k total stars. [github.com/affaan-m/ECC](https://github.com/affaan-m/ECC)
- **caveman** (JuliusBrussee, open source) - A skill/proxy that makes agent responses terse to cut output-token use, claiming a 65% average reduction; works with Claude Code and 30+ other agents. 112.4k total stars. [github.com/JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman)
- **context-mode** (mksglu, open source) - An MCP server that sandboxes large tool outputs (test runs, API responses, browser snapshots) outside the model's context window, indexing them for retrieval instead; claims up to 98% context reduction. 29.7k total stars. [github.com/mksglu/context-mode](https://github.com/mksglu/context-mode)
- **billion-context** (ranxianglei, open source) - A proxy between a coding agent and its model API that incrementally, reversibly compresses older conversation turns so long sessions don't hit context limits; self-reports a 4.5-month study of 174k model calls with no context-window violations. Useful if your agent keeps getting truncated mid-task. [npm: billion-context](https://cdn.jsdelivr.net/npm/billion-context@0.1.126/README.md)
- **scientific-agent-skills** (K-Dense-AI, open source) - A library of 177 ready-to-use agent skills turning Claude Code/Codex/Cursor into domain scientists (biology, chemistry, medicine, drug discovery), with access to 100+ specialized databases. 50.4k total stars. [github.com/K-Dense-AI/scientific-agent-skills](https://github.com/K-Dense-AI/scientific-agent-skills)
