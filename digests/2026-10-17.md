# AI Dev Weekly - Week ending 2026-10-17

## 1. New models, products & tools (max 8)

- **ArtCraft** (storytold / Brandon Thomas, open source) - A suite of native Rust, Electron-free creative apps (image, vector, video, PDF, audio editors) built as clean-room alternatives to Adobe-style tools, rendered with egui/wgpu. Repos went public September 30-October 7; +20,267 stars this week on GitHub's weekly trending chart, 31,662 total. [github.com/storytold/artcraft](https://github.com/storytold/artcraft)
- **iFixAi** (ifixai-ai, open source) - An independent auditing platform for AI agents: connect one via GitHub or MCP and it runs red-team-style inspections to catch misalignment (fabricated outputs, deceptive behavior) before it reaches users. Launched in the past ~3 weeks; +6,913 stars this week on GitHub's weekly trending chart, 29,125 total. [github.com/ifixai-ai/ifixai](https://github.com/ifixai-ai/ifixai)

## 2. AI dev tools, software & techniques (max 10)

- **skills** (vercel-labs, open source) - Vercel's official CLI for the open Agent Skills standard; `npx skills add` installs, discovers and updates skills across 40+ coding agents (Claude Code, Codex, Cursor, etc.), checked into your repo like any other dependency. +1,731 stars this week, 35,360 total. [github.com/vercel-labs/skills](https://github.com/vercel-labs/skills)
- **CLI-Anything** (HKUDS, open source) - Runs a 7-phase pipeline (analyze, design, implement, test, document, publish) to auto-generate a production CLI for any existing piece of software, so an agent can drive apps like GIMP or Blender, or a cloud API, from the command line instead of screen-scraping a GUI. +580 stars today on GitHub's daily trending chart, 53,980 total. [github.com/HKUDS/CLI-Anything](https://github.com/HKUDS/CLI-Anything)
- **Orca** (stablyai, open source) - A desktop app that runs Claude Code, Codex, OpenCode and Pi side by side, each in its own git worktree, with an embedded browser and GitHub/Linear integration; send one prompt to several agents and merge whichever result you like best. +829 stars today, 95,263 total. [github.com/stablyai/orca](https://github.com/stablyai/orca)
- **ai-memory** (akitaonrails, open source) - A single Rust binary giving any coding agent (20+ harnesses supported) long-term memory via a git-backed markdown wiki; lifecycle hooks capture work as it happens and the next session starts from a handoff summary. Default path makes zero LLM calls. ~9.8k stars, +208 today. [github.com/akitaonrails/ai-memory](https://github.com/akitaonrails/ai-memory)
- **TencentDB-Agent-Memory** (TencentCloud, open source) - A team-level memory hub that turns chats, docs and code into shared memory assets multiple agents/developers can draw on, instead of each developer's agent starting from zero context. +1,498 stars this week, 29,502 total. [github.com/TencentCloud/TencentDB-Agent-Memory](https://github.com/TencentCloud/TencentDB-Agent-Memory)
- **xerj** (xerj-org, open source) - A single-binary, no-JVM search engine that speaks the Elasticsearch API; point it at a folder of code, docs, logs and PDFs so an agent can query them instead of loading whole files into context. +1,102 stars today, 7,699 total. [github.com/xerj-org/xerj](https://github.com/xerj-org/xerj)
- **KittenTTS** (KittenML, open source) - A sub-25MB, CPU-only text-to-speech model (Nano/Micro/Mini variants) for adding a local voice to dev tools or demos without a GPU or API bill. +413 stars this week, 16,123 total. [github.com/KittenML/KittenTTS](https://github.com/KittenML/KittenTTS)
