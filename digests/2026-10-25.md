# AI Dev Weekly - Week ending 2026-10-25

## 1. New models, products & tools (max 8)

- **REA** (morluto, open source) - An MCP server/CLI giving coding agents reverse-engineering tools, from app behavior down to native binaries and Android APKs. Three weeks after its October 5 launch it's still accelerating: +88,243 stars this week on GitHub's weekly trending chart, 378k total. [github.com/morluto/rea](https://github.com/morluto/rea)

## 2. AI dev tools, software & techniques (max 10)

- **Spec Kit** (GitHub, open source) - An open-source toolkit (`specify-cli`) that drives coding agents through a structured spec → plan → tasks → implement workflow instead of ad-hoc prompting, via slash commands in Claude Code, Copilot and Gemini CLI. Treat your spec as the durable artifact and regenerate code from it when requirements change; one survey counts 30+ competing "spec-driven development" frameworks now in the space. [github.com/github/spec-kit](https://github.com/github/spec-kit)
- **security-audit-skill** (Cloudflare, open source) - A coding-agent skill that runs a multi-phase, isolated-sub-agent security audit and produces verified, machine-readable findings instead of a prose report. Drop it into Claude Code/Codex/Cursor to get a repeatable, auditable vuln scan before shipping; +2,271 stars today on GitHub's daily trending chart, 44.2k total. [github.com/cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill)
- **graphify** (Graphify-Labs, open source) - Parses a codebase (plus docs, SQL schemas, configs) with tree-sitter into a local knowledge graph - "god nodes," clusters, cross-file call/import/inheritance links - that a coding agent can query instead of re-reading files. `uv tool install graphifyy` wires it into Claude Code, Codex or Cursor as always-on context; +6,875 stars this week on GitHub trending, 134k total. [github.com/Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify)
- **ruflo** (ruvnet, open source, formerly Claude Flow) - A meta-harness that wraps Claude Code or Codex to coordinate swarms of agents with shared memory and 300+ MCP tools, for breaking a task into a hierarchical multi-agent run (`ruflo swarm init --topology hierarchical`) instead of one long single-agent session. +3,349 stars this week on GitHub trending, 79k total. [github.com/ruvnet/ruflo](https://github.com/ruvnet/ruflo)
- **OpenShell** (NVIDIA, open source) - An Apache-2.0 sandboxed runtime that puts each autonomous agent in its own container and enforces declarative YAML policy at the infrastructure level, so a compromised or misbehaving agent can't override its own guardrails. Useful if you're letting agents like Claude Code, Codex or OpenHands run with real file/shell access and want a security boundary underneath the prompt. +893 stars today on GitHub's daily trending chart, 19.4k total. [github.com/NVIDIA/OpenShell](https://blogs.nvidia.com/blog/secure-autonomous-ai-agents-openshell) [GitHub](https://github.com/NVIDIA/OpenShell)
- **hallmark** (Nutlope, open source) - A design skill for Claude Code, Cursor and Codex that runs dozens of automated checks to catch generic "AI-slop" UI and nudges output toward one of ~20 curated visual themes; can audit existing code without editing, or do a full brand-preserving redesign. +570 stars today on GitHub's daily trending chart, 32k total. [github.com/Nutlope/hallmark](https://github.com/Nutlope/hallmark)
- **opencode** (anomalyco, open source) - An established open-source coding agent that connects to many model providers (an alternative to Claude Code/Codex/Copilot) and ships a GitHub Action so reviewers can trigger it from PR comments with `/oc`. Now one of the largest agent repos on GitHub: +6,765 stars this week, 221k total. [github.com/anomalyco/opencode](https://github.com/anomalyco/opencode)
- **DeepSeek-V4.1-Flash** (DeepSeek) - An MIT-licensed, open-weight MoE coding model (552B total/8-16B active params, 1M-token context) that scores 74.2 on DeepSWE v1.1 and 90.6 on Terminal-Bench 2.1 per its model card, and can be self-hosted instead of called through an API. [thenextweb.com](https://thenextweb.com/news/deepseek-v4-1-flash-launch-v4-pro-retired-price-cut)
