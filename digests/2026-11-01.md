# AI Dev Weekly - Week ending 2026-11-01

## 1. New models, products & tools

**Kimi K3.1 Pro** (Moonshot AI) - a new frontier agentic/coding model (2.8T total params, 104B active in its MoE) with a 1M-token context window, released Oct 23, 2026, with open weights due Nov 4; API variants `kimi-k3.1-pro` and a 2-3x faster `-highspeed` tier are live now. Moonshot reports 65.7% on Terminal-Bench 4.0, close behind Claude Opus 5.5. [MarkTechPost](https://www.marktechpost.com/2026/10/23/moonshot-ai-kimi-k3-1-pro-open-weight-model/)

**OpenMausBot** (milind-soni) - a self-hosted, open-source alternative to Grok Bot: an Electron chat app where each "bot" is a persistent agent running on your own Claude Code, Codex, or Grok CLI logins, with an MCP server for driving it from Claude Desktop or Cursor. Launched on Product Hunt Oct 13, 2026. +1,304 stars today, 9.5k total. [GitHub](https://github.com/milind-soni/OpenMausBot)

## 2. AI dev tools, software & techniques

**Agent Skills / Superpowers** (obra, Prime Radiant) - a widely-adopted methodology for packaging reusable instructions, scripts, and checklists ("skills") that coding agents load automatically when a task matches, instead of relying on ad-hoc prompting. Useful as a template for structuring your own team's Claude Code/Codex conventions into shareable, versioned skill folders. +5,474 stars this week, 310k total. [GitHub](https://github.com/obra/superpowers)

**Security Audit Skill** (Cloudflare) - an open-source agent skill that turns a coding agent into a six-phase security auditor (recon, coverage-led hunting, candidate validation, independent verification, reporting), the same harness Cloudflare uses to seed its own vulnerability discovery. Drop it into Claude Code/Codex to get verified, machine-readable findings instead of a raw grep-and-guess pass. +12,838 stars this week, 55.2k total. [GitHub](https://github.com/cloudflare/security-audit-skill)

**Anti-"AI slop" design skills - Hallmark & Impeccable** (Together AI's Nutlope; Paul Bakaus) - two competing agent skills that give coding agents a design vocabulary (layout/typography/motion rules, pre-ship gates) so Claude Code/Cursor/Codex stop producing generic, template-looking UI. Wire one in as a design-review step before shipping any AI-generated frontend. Hallmark: +11,766 stars this week, 43.8k total. Impeccable: +11,323 stars this week, 98.1k total. [Hallmark](https://github.com/Nutlope/hallmark) / [Impeccable](https://github.com/pbakaus/impeccable)

**claude-mem** (Alex Newman) - an open-source persistent-memory layer that captures tool-use observations during an agent session, summarizes them, and reinjects relevant context into future sessions, working across Claude Code, Codex, Gemini, and Copilot. Useful for long-running or multi-day projects where agents currently "forget" everything between sessions. +3,518 stars this week, 107.7k total. [GitHub](https://github.com/thedotmack/claude-mem)

**Lightpanda** - an AI-native headless browser written from scratch in Zig (not a Chromium fork), with a built-in natural-language `agent` mode and a native MCP server, claiming far lower memory and faster execution than headless Chrome for agent-driven browsing. Drop-in compatible with Playwright/Puppeteer via CDP for browser-automation agents that need to run at scale. +929 stars today, 39.1k total. [GitHub](https://github.com/lightpanda-io/browser)

**Orkas** (Orkas-AI) - a local-first desktop app where a "Commander" agent breaks a goal into to-dos and dispatches a team of specialist sub-agents, including external CLI agents like Claude Code and Codex, keeping all data and API keys on your machine. A lightweight way to orchestrate multiple coding agents on one task without building your own harness. +1,118 stars today, 6.1k total. [GitHub](https://github.com/Orkas-AI/Orkas)
