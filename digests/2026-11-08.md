# AI Dev Weekly - Week ending 2026-11-08

## 1. New models, products & tools

**DeepInfer** (DeepSeek) - a high-performance inference framework DeepSeek open-sourced for offline, large-scale serving of its own models (currently DeepSeek-V4.1-Flash) on NVIDIA SM100 GPUs or Huawei Ascend 950 NPUs; it's the same engine behind DeepSeek's production services, built on vLLM. New repo (created within the last month). 25.6k stars. [GitHub](https://github.com/deepseek-ai/DeepInfer)

**DSH SuperAgent** (DeepSeek, research prototype) - a proactive coding-agent prototype for DeepSeek's open agent harness (DSH) that watches a GitHub repo, opens its own work item when someone authorized asks for something, does the work in its own session, and replies with a PR. Explicitly a reference prototype, not a finished product. New repo. 20.8k stars. [GitHub](https://github.com/deepseek-ai/dsh-superagent-prototype)

**Craft Anything** (storytold) - an early-alpha, pure-Rust tool/MCP server that points a coding agent (Claude Code) at a website, app or game, inspects how it works, then builds and iteratively refines your own version against the original, with a "clean room" mode that works only from what's externally visible. New repo. 20.4k stars. [GitHub](https://github.com/storytold/craft-anything)

**Mistral Large 4** (Mistral AI) - Mistral's new flagship: a natively multimodal 1T-parameter MoE (49B active), previewed via API on Oct 6 with open weights published in late October. One benchmark roundup put it at 61.7% on DeepSWE v1.1 and 28.3% on Terminal-Bench 4, behind Chinese coding models like Kimi K3 on the same tests. [eesel.ai](https://www.eesel.ai/blog/mistral-large-4)

## 2. AI dev tools, software & techniques

**T3 Code** (pingdotgg) - an "agent harness control surface": a mobile app, web app and Electron desktop app that let you check on and steer coding agents (Claude Code, Codex, Cursor, Grok Build, OpenCode, Antigravity) already running on your own machine, from your phone. Useful for monitoring or nudging a long-running agent session away from your desk. +16,782 stars this week, 51.1k total. [GitHub](https://github.com/pingdotgg/t3code)

**Claude Code Game Studios** (Donchitos) - a drop-in `.claude/` config that turns a Claude Code session into a 49-agent, three-tier game studio (directors, leads, specialists) with slash-command skills for every phase from design docs to QA, plus engine-specific agent sets for Godot, Unity and Unreal. A concrete template for structuring a large multi-agent workflow against one codebase. +6,018 stars this week, 36.5k total. [GitHub](https://github.com/Donchitos/Claude-Code-Game-Studios)

**PR-Agent** (community, formerly Qodo/CodiumAI) - an open-source agent that posts automated review comments, PR descriptions and suggested fixes on pull requests; the project has moved out of Qodo into its own community-owned org and is now open to outside maintainers. Drop it into CI as a baseline automated review pass before a human looks at the diff. +1,523 stars this week, 15.4k total. [GitHub](https://github.com/The-PR-Agent/pr-agent)

**Worktrunk** (Maximilian Roos) - a Rust CLI (`wt`) for Git worktree management built specifically for running several coding agents in parallel, each in its own working directory, with hooks, LLM-generated commit messages and shared build caches across worktrees. Worth adopting once you're running more than one Claude Code/Codex session against the same repo at a time. +2,184 stars this week, 11.9k total. [GitHub](https://github.com/max-sixty/worktrunk)

**google/skills** (Google) - Google's official Agent Skills repository, covering Google Cloud technologies (BigQuery, Cloud Run, Firebase, GKE, the Gemini API) plus Well-Architected Framework and onboarding recipes; install with `npx skills add google/skills` for use with Antigravity, Gemini CLI or other agents. A ready-made, vetted skill set if your stack touches GCP. +449 stars today, 23.3k total. [GitHub](https://github.com/google/skills)

**Auto Ontology** (NVIDIA) - an open-source "context layer" that builds an ontology from your database metadata, maps business terms to columns, and checks agent-generated SQL against certified definitions, exposed to agents via MCP, CLI and API. Targets the common failure mode of agents writing plausible-looking but wrong SQL against an unfamiliar schema. +1,322 stars today, 9.7k total. [GitHub](https://github.com/NVIDIA/auto-ontology)

**unslop** (Damir Sokolovsky) - a Claude Code/Codex skill that audits a UI for "AI slop" tells (purple gradients, glow effects, emoji labels, uneven spacing), proposes a design direction, and fixes the screen in passes; works on Next.js/React/Vue/Svelte/Tailwind or a live site URL. The newest entrant in the anti-slop design-skill category alongside Hallmark and Impeccable. 11.3k stars. [GitHub](https://github.com/heydamir/unslop)

**billion-context** (ranxianglei) - an open-source context-compression plugin that sits between a coding agent (Claude Code, Codex, Aider) and the model API, folding older parts of a long session into layered summaries it can restore on demand, aiming to keep month-long sessions running inside a small context window. +185 stars today, 4.6k total. [GitHub](https://github.com/ranxianglei/billion-context)
